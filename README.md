# 雅思阅读错题本

把你做过的雅思阅读整理成自己的错题本。你可以重做错题、对照原文看解析，也可以按「今日」里的计划复习。模板自带分栏阅读、判分、原文定位、解析、每日复习计划和进度保存。把模板下载到自己的电脑，让 AI 帮你准备题库，平时在浏览器里刷题。

## 开始使用

把下面这句话发给能操作本机的 WorkBuddy 或其他 AI：

> 请按 https://github.com/Limcrence/ielts-reading-notebook/blob/main/AI_PROMPT.md 帮我导入学校已批阅的雅思阅读周测和作业。我来登录，你做完告诉我一共几份、成功几份、漏了哪几份。

在弹出的学校官网窗口登录，剩下的由 AI 操作。程序会显示“已读取几份/共几份”。中途关掉也能在下次继续。每个人用自己的学校账号和电脑即可。[给 AI 的操作步骤](./AI_PROMPT.md)

## 以后怎么用

| 你想做什么 | 怎么做 |
| --- | --- |
| 继续刷题 | 用同一台电脑、同一个浏览器打开原来的网址，点「继续我的复习」。如果网页打不开，把「帮我重新打开错题本，用原来的网址和进度」发给 AI。 |
| 加一份新周测 | 打开原来的 AI 任务，发「帮我把这次已批阅的周测加进去，保留以前的题和进度」。按它的指引导入更新后的题库。 |
| 留一份备份 | 在做题页右上角点「⋯」→「导出备份」，另外保留 AI 生成的题库文件。恢复时先导入题库，再用「⋯」→「导入备份」恢复复习进度。 |

题库和复习进度保存在本机。学校报告和自己的题库留在本地 `.private/` 文件夹，进度备份也保存在自己能找到的位置。这里公开的是应用、原创示例和执行手册。

## 能在学校电脑和自己的设备之间接着刷吗？

当前下载的模板采用本机保存。平时在原电脑上用同一个浏览器和网址继续刷，题库导入一次就够了。AI 的聊天记录能否跨设备查看，与错题本数据是否同步是两回事。

| 用法 | 怎么接着做 |
| --- | --- |
| 偶尔换设备 | 新设备能运行模板并打开错题本时，首次导入个人题库和进度备份。之后题库有新增才更新题库文件，换设备时用新导出的进度备份恢复答案、笔记和复习计划。 |
| 经常切换，想打开就接着刷 | 需要另行开通云同步网站。开通后，第一台设备导入一次自己的题库，有本机进度的话再导入备份。之后在学校电脑、手机或 iPad 打开同一网址，输入自己的同步码，自动取回个人题库和复习进度。 |

云同步已有本地试验版，**目前没有公开开通的同步网址**。如果以后开通，只需要提供者配置一套同步服务。每位同学只用自己的同步码，学校设备需要能访问该网址。试验版会在设备上加密并同步题库和进度。个人题库文件无需提交到 GitHub。

## 手动运行

如果你习惯用终端，可以在模板文件夹运行以下命令。Node.js 版本以 [package.json](./package.json) 为准。

```sh
npm ci
npm run check:library
npm run dev
```

启动后打开 `http://127.0.0.1:5173/`。个人题库用 `npm run check:library -- .private/reading-library.json` 检查，应用用 `npm run build` 检查构建。题库格式见 [示例](./examples/reading-library.json) 和 [校验规则](./src/lib/library-import.ts)。
