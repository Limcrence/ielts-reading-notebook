# 雅思阅读错题本模板

这个模板可以分栏重做阅读错题，提交后查看判分、原文定位和解析。它也会安排每日复习，并在同一浏览器里记住复习进度。示例采用自编文章和虚构作答。

## 用 WorkBuddy 制作自己的错题本

1. 解压模板。在 WorkBuddy 或同类 AI 助手里打开解压后的整个文件夹。
2. 把 [WORKBUDDY_PROMPT.md](./WORKBUDDY_PROMPT.md) 全文粘贴到聊天里。
3. 先让助手打开示例。如果助手能操作学校网页，就在官方学生端自己登录。已有报告文件也可以交给助手在项目目录里整理。
4. 当助手生成 `.private/reading-library.json` 并通过校验后，打开错题本，点「导入我的题库」，选择这个文件。

如果学校报告没有可读原文、正确答案或逐题结果，先请助手说明缺了什么。模板里的示例可以随时打开练习。

## 手动启动

需要 Node.js 22.13 或更新的受支持版本。在项目目录运行以下命令。

```sh
npm ci
npm run check:library
npm run dev
```

在浏览器打开 `http://127.0.0.1:5173/`。同一地址会使用同一份本机题库和复习进度。换电脑、换浏览器或清除站点数据前，可以从错题本右上角导出进度备份，并保留自己导入的题库 JSON。恢复时先导入题库，再导入进度备份。

私有资料放在 `.private/` 目录中。题库从文件选择器进入浏览器，新增题库会按稳定编号合并。看到编号冲突时，核实是否是不同版本的题或文章，再给不同版本使用新编号。示例和个人复习进度各自保存。

下面两条命令分别检查个人题库格式和构建。

```sh
npm run check:library -- .private/reading-library.json
npm run build
```

JSON 结构可以参照 [示例题库](./examples/reading-library.json)。[数据校验器](./src/lib/library-import.ts) 给出实际接受的字段与规则。
